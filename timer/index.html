How it works

The timer counts the minutes the games are open and visible on this browser on this device. When the daily limit is reached, every page shows a "time's up" screen until tomorrow, unless a parent adds time with the PIN. Other devices are not affected, and nothing is sent anywhere: the timer and the PIN (stored scrambled) stay in this browser.

It is a nudge, not a lock. Clearing this site's data, a private window or a different browser gets around it. For a stronger limit, use Google Family Link (Chromebook, Android), Screen Time (iPad, iPhone) or Microsoft Family Safety (Windows).

Forgot the PIN? Clearing this site's data in the browser settings removes the timer, but it also removes game progress, so make a save code first.
